# Лабораторная работа №1 

В данном репозитории реализована система автоматического деплоя приложения Catty через GitHub Webhooks.

## Список созданных файлов:
1. **deploy_handler.py** (v5.0) — Python-скрипт для обработки вебхуков. Автоматически делает `git fetch/reset`, убивает старые процессы и запускает uvicorn с пробросом актуального SHA через `DEPLOY_REF`.
2. **frpc.ini** — конфигурация туннеля FRP для проброса порта 8080 наружу.
3. **requirements.txt** — зависимости проекта.

## Инструкция по запуску:
1. Запустить туннель: `./frpc -c frpc.ini`
2. Запустить обработчик: `sudo python3 deploy_handler.py`
3. Приложение развернется на порту 8181 и будет доступно через прокси.
